# Saúde com Dados

Disciplina do [Centro de Informática (CIn) da UFPE](https://cin.ufpe.br), conduzida pela **Professora Dra. Maira Santana** ([mas6@cin.ufpe.br](mailto:mas6@cin.ufpe.br)), em parceria com o **Hospital das Clínicas da UFPE**.

Esta organização reúne os repositórios dos projetos desenvolvidos ao longo da disciplina, que aplicam dados e tecnologia a problemas reais da área da saúde.
